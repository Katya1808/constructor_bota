# 🤖 Конструктор ботов Alpina.GPT

Django-приложение для создания и управления Telegram-ботами на базе LLM (GPT/Qwen).

## 💡 О проекте
Это не просто один бот, а **платформа-конструктор**. Администратор может через панель управления Django создать неограниченное количество ботов, задать для каждого уникальные сценарии и системные промпты 
(например, "Ты HR-менеджер" или "Ты помощник по обучению"). Конечный пользователь пишет боту в Telegram, а система динамически формирует запрос к нейросети на основе настроенного сценария и 
возвращает "умный" ответ. Программист для изменения логики бота не требуется.

## 🛠 Стек технологий
- **Python 3.11**
- **Django 4.2** + **Django REST Framework** (для API управления)
- **OpenAI API / OpenRouter (Qwen)** (для генерации ответов)
- **python-telegram-bot** (для интеграции с Telegram через polling)
- **SQLite** (для хранения сущностей)
